LTT-TOOL

Bộ công cụ Revit giúp dựng nhanh Tường – Dầm – Cột từ CAD, tạo Dimension tới trục Grid, so sánh model với CAD, kiểm tra Warning và đụng độ giữa các mô hình.

LTT-TOOL làm được gì

Các lệnh trong LTT-TOOL

Dim và Grid

Dim tới Grid
Tự động tạo Dimension từ dầm/tường/cột tới trục Grid song song gần nhất trong mặt bằng đang mở.
Dim Sàn tới Grid
Tự động tạo Dimension từ Sàn tới trục Grid gần nhất.
Tìm Grid trùng
Quét toàn bộ Grid trong dự án, phát hiện các Grid tên khác nhau nhưng trùng vị trí hình học.

Làm việc với CAD

Link CAD Tự động
Link file CAD (DWG/DXF) vào model, tự căn Positioning khớp đúng Grid Revit, chọn Level, Import units, Colors, bật/tắt Layer ngay trong view.
Vẽ Tường từ CAD
Đọc đường nét từ CAD theo Layer chọn trước, dựng Tường tương ứng.
Vẽ Dầm từ CAD
Đọc đường nét từ CAD theo Layer chọn trước, tự động đặt Dầm theo tim hoặc theo cặp 2 mép dầm.
Vẽ Dầm theo nhãn CAD
Đặt Dầm dựa theo nhãn dầm ghi trên bản vẽ CAD.
Vẽ Dầm nhanh từ CAD
Cách đặt Dầm từ CAD rút gọn thao tác, dùng khi cần dựng nhanh.
Vẽ Cột từ CAD
Đọc hình học từ CAD theo Layer chọn trước, tự động đặt Cột theo tâm hình kín, giao điểm 2 đường tim, hoặc click điểm trực tiếp.
So sánh Dầm CAD
So sánh Dầm trong model với bản vẽ CAD để phát hiện chỗ lệch hoặc thiếu.
So sánh Tường CAD
So sánh Tường trong model với bản vẽ CAD để phát hiện chỗ lệch hoặc thiếu.

Chỉnh sửa Tường

Vẽ lớp trát
Tạo lớp trát cho Tường.
Ngắt Tường
Ngắt Tường tại vị trí cần thiết.
Cắt Tường tự động
Tự động cắt Tường, không phải thao tác thủ công từng đoạn.

Kiểm tra mô hình

Kiểm tra đụng độ
So hình học giữa file đang mở và 1 Revit Link, chọn Category từng bên, lọc theo View hoặc Level, có chế độ kiểm tra khoảng hở theo phương đứng. Bảng kết quả bấm để tới đúng vị trí trong 3D, xuất được CSV.
Tìm Warning
Tìm và liệt kê các Warning trong model để xử lý.
Đếm Dầm/Cột/Vách
Thống kê số lượng Dầm, Cột, Vách trong model.
Auto Disallow Join
Bật/tắt tự động Disallow Join; trạng thái hiện tại hiện ngay trên nút.
Tải LTT-TOOL_1.0.6.exe

Đóng Revit trước khi cài đặt. Installer sẽ tự động ghi đè bản cũ (nếu có), không cần gỡ cài đặt trước.

Hướng dẫn cài đặt

  1. Tải file cài đặt phía trên.
  2. Đóng Revit nếu đang mở.
  3. Chạy file .exe vừa tải, cho phép quyền Admin nếu được hỏi.
  4. Làm theo hướng dẫn cài đặt (Next → Install).
  5. Mở lại Revit — tab LTT.TOOL sẽ xuất hiện trên Ribbon.
  6. Bấm Đăng nhập trên tab LTT.TOOL để kích hoạt.
