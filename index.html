Revit Add-in

AutoDimToGrid

Phiên bản 1.0.2 · Revit 2024

Bộ công cụ tự động tạo Dimension tới trục Grid gần nhất, chẩn đoán Grid trùng vị trí, và hỗ trợ Link/đọc file CAD để dựng nhanh Tường – Dầm – Cột trong Revit.

  • Dim tới Grid — tự động tạo Dimension từ dầm/tường/cột tới trục Grid song song gần nhất trong mặt bằng đang mở
  • Tìm Grid trùng — quét toàn bộ Grid trong dự án, phát hiện các Grid tên khác nhau nhưng trùng vị trí hình học
  • Link CAD Tự động — Link file CAD (DWG/DXF) vào model, tự căn Positioning khớp đúng Grid Revit, chọn Level, Import units, Colors, bật/tắt Layer ngay trong view
  • Vẽ Dầm từ CAD — đọc đường nét từ CAD theo Layer chọn trước, tự động đặt Dầm theo tim hoặc theo cặp 2 mép dầm
  • Vẽ Cột từ CAD — đọc hình học từ CAD theo Layer chọn trước, tự động đặt Cột theo tâm hình kín, giao điểm 2 đường tim, hoặc click điểm trực tiếp
⬇ Tải AutoDimToGrid_Setup_1.0.1.exe
⚠️ Đóng Revit trước khi cài đặt. Installer sẽ tự động ghi đè bản cũ (nếu có), không cần gỡ cài đặt trước.

Hướng dẫn cài đặt

  1. Tải file cài đặt phía trên
  2. Đóng Revit nếu đang mở
  3. Chạy file .exe vừa tải, cho phép quyền Admin nếu được hỏi
  4. Làm theo hướng dẫn cài đặt (Next → Install)
  5. Mở lại Revit — tab AutoDimToGrid sẽ xuất hiện trên Ribbon
